# 영어 따라 말하기 (Katie Dill, Stripe 강연)

바로 쓰기: https://braincoool-code.github.io/english-shadowing/
(Chrome 권장. 첫 녹음 때 마이크를 "허용"하세요.)

영상: https://www.youtube.com/watch?v=GLvFTMtw4Jk (영어 원본 음성)

## 기능
- 문장 301개, 단어별 시간에 맞춰 듣기·하이라이트
- 속도 0.6 / 0.75 / 0.9 / 1.0, 반복 1·3·5번
- 듣고 따라 말하기: 문장을 듣고 같은 길이만큼 말할 시간을 줌
- 끝에서부터 쌓기: 긴 문장을 뒤 덩어리부터 붙여 가며 연습
- 단어를 누르면 연사의 원래 소리로 그 단어만 재생
- 녹음하고 점수 보기 / 겹쳐 말하며 녹음 / 원본 → 내 목소리 비교
- 한국어 뜻(직접 번역), 자막 가리기, 문장 찾기, 80% 미만 문장 모아 보기
- 기록은 브라우저(localStorage)에만 저장

## 참고
- 문장은 유튜브 자동 자막 기반이며, 명백한 오인식 18곳만 고쳤습니다.
- 점수 = 브라우저 음성 인식이 알아들은 단어 비율(명료도)입니다. 억양·강세는 귀로 비교하세요.
